What changed

  • Every day has its text: start time and title, wrapping to 2 lines, with the person's colour on the left edge.
  • Up to 3 entries per day, then "+N more". Busy days stay readable instead of shrinking the text.
  • All-day events are solid colour; a trip over several days is one continuous bar (ski weekend 20–22).
  • Weather icons on the days that have a forecast (about the next week).
  • A narrower font is used just for the event text, so more of each title fits in the narrow portrait columns.
  • The "Coming up" list is gone, giving the grid the full height.
